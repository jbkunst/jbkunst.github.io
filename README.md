# jkunst.com

Código fuente de [jkunst.com](https://jkunst.com), el sitio personal y blog de
Joshua Kunst, construido con Quarto y publicado mediante GitHub Pages. El
nombre del repositorio es `jbkunst.github.io`, pero no es el dominio público del
sitio.

Los posts viven en `blog/posts/`, comparten su configuración de R mediante
`blog/_R/post_setup.R` y se publican en `docs/` al renderizar el proyecto.

Las convenciones de edición, visualización y renderizado se mantienen en
[`AGENTS.md`](AGENTS.md), que es la guía operativa autoritativa para trabajar en
este repositorio.
